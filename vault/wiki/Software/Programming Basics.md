# Programming Basics

Code is a set of instructions for a computer, similar to a recipe, and programs are built from fundamental building blocks like variables, conditionals, loops, and functions.

## Key points

- Code is a set of instructions that tells a computer what to do.
- Variables are used for storing data.
- Conditionals allow a program to make decisions.
- Loops repeat actions so they do not need to be repeated.
