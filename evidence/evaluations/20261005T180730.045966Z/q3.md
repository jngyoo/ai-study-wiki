# q3

## Question
What is an embedding, and how does vector-search-based RAG use embeddings to find documents relevant to a question? Does this process retrain the answering model?

## Expected behavior
Explain numerical vector representations, similarity search, retrieved passages entering context, and no weight retraining. Cite both Class 4 and Class 5.

## Actual answer
Embeddings are numerical representations of text stored in a vector database, where similar meanings are located close together [class5:vector-databases-search-by-meaning:1]. Vector-search-based RAG uses these embeddings to find document chunks near the question by searching for similar meanings [class5:vector-databases-search-by-meaning:1]. This process does not retrain the answering model [class5:building-a-tiny-rag-demo:1].
