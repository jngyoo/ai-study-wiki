## Question
Each time I changed my model, I checked its score on the final test data and picked the settings with the highest score. Why can I not trust that evaluation, and which data should I use to choose settings?

## Expected behavior
Test scores must not guide development. Choose settings using validation data and keep final test data untouched until choices are fixed.

## Actual answer
If you keep changing the model after seeing its test score, that score starts guiding development, so the final test set should be kept untouched until your choices are fixed [class3:keep-a-test-set-outside-development:1]. You should use validation data to choose settings [class3:keep-a-test-set-outside-development:1].
